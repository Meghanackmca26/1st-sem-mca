Prompt Engineering - Customer Query Classification

1. Introduction
This project aims to classify customer queries received by an e-commerce company into different categories using prompt engineering. It helps identify customer problems related to delivery, shipping, refunds, payments, cancellations, defective products, returns, and account issues. 

2. Prompt
I will provide customer queries from an e-commerce company. Read and understand each query carefully and classify it into one of the following categories:
Delivery, Shipping, Refund, Payment, Cancellation, Defect, Return, Account, or Unknown.

3. Sample Inputs and Expected Outputs

1. Input:I placed an order last week, but it hasn't reached me.
Expected Output:
Delivery

2. Input:The tracking status has not changed for three days.
Expected Output:
Shipping

3. Input:When will I get my money back for the cancelled order?
Expected Output:
Refund

4. Input:My credit card payment failed during checkout.
Expected Output:
Payment

5. Input:Please stop processing my recent order.
Expected Output:
Cancellation
